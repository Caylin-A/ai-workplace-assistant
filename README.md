# AI Workplace Assistant

Build a modern, responsive web app called AI Workplace Productivity Assistant.

Create it as a frontend-focused SaaS application with no custom backend, database, authentication, or unnecessary features. Keep the implementation simple and lightweight.
Design

Clean, modern professional SaaS dashboard

Pastel pink, black and white colour palette

Left sidebar navigation

Responsive desktop and mobile layout

Modern cards, buttons, forms and editable output areas
Features
1. Smart Email Generator

Users enter the purpose/key points of an email and select:

Formal

Friendly

Persuasive

Generate a professional email based on the user’s actual input. Make the generated email editable and include Copy and Clear buttons.
2. Meeting Notes Summariser

Users can paste meeting notes, articles, or a website URL.

Generate an AI summary based on the provided content and organise the result into:

Summary

Action Items

Decisions

Deadlines

Make the output editable with Copy and Clear buttons.
3. AI Task Planner

Users enter their tasks, deadlines and available time and choose Daily or Weekly.

Generate a prioritised schedule based on their actual input. Display:

Priority

Task

Date/Time

Deadline

Make the schedule editable.
AI

Use real AI-generated responses based on user input rather than hardcoded or generic responses. Use structured prompts for each feature. If an AI API/integration is required, use the simplest supported client-side approach and do not create a custom backend.

Include loading, empty and error states.
Responsible AI

Display this disclaimer:

“AI-generated content may contain errors. Review and verify outputs before using them for workplace decisions or communication.”

Do not add authentication, database storage, payment features, analytics, or other features outside the requirements. Focus on making these three AI productivity tools polished, functional and easy to demonstrate.
